# فهرس مجلد التوثيق (docs)

كل ملف في سطر واحد. لم ننقل الملفات، لأن الشفرة والتوثيق يشيران إلى مساراتها.
أكثر الملفات بالإنجليزية. ملفات التحدي والمصادر بالعربية.

## التحدي (Islamic AI Challenge)

| الملف | ما فيه |
|---|---|
| `CHALLENGE_BASELINE.md` | نسخة البداية (baseline) قبل أيام التحدي، ومكوّناتها، والوسم `challenge-baseline-2026-10-03`. |
| `CHALLENGE_SPEC.md` | ما بُني في أيام التحدي: الحسابات والرصيد، والبحث والتحقق من الاقتباس، وخادم MCP (MCP server). |
| `CHALLENGE_RESULTS.md` | قياس التحقق من الاقتباس: النتائج، والبديل المسمّى، وطريقة إعادة التشغيل، والحدود. |
| `SOURCES.md` | توثيق المحتوى والمصادر: الكتب، وقاعدة الحقوق، وطريقة التحقق من النص، والحدود. |
| `THIRD_PARTY_LICENSES.md` | سجل المكوّنات الخارجية ورخصها: الحزم، والخطوط، والنماذج، والخدمات. |
